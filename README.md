# GlassOS 🖥️✨

A modular, browser-based desktop environment and interactive dashboard built with vanilla HTML5, modern CSS3, and JavaScript. 

![NexusOS Preview](https://img.shields.io/badge/status-active-success.svg) ![License](https://img.shields.io/badge/license-MIT-blue.svg)

## 🌟 Features

* **Draggable Window Manager:** Smooth z-index stacking, custom window focus management, and fluid mouse-drag logic.
* **Persistent Notes App:** Real-time auto-saving utilizing the browser's `localStorage` so your notes never disappear on refresh.
* **Weather & Terminal Widgets:** Sleek, modern mock UI modules built with a cyberpunk/developer-focused aesthetic.
* **Custom Dock & Top Bar:** Includes live system time tracking, active window status indicators, and quick-launch controls.

---

## 🛠️ Built With

* **HTML5** – Semantic structure and layout architecture.
* **CSS3** – Glassmorphism aesthetics, custom gradients, flexbox/grid, and fluid animations.
* **JavaScript (ES6+)** – DOM manipulation, event bubbling, state persistence, and window lifecycle management.
* **FontAwesome & Google Fonts** – Icons and typography (*JetBrains Mono* & *Inter*).
